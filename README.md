An entry for the make.fun "Weirdest Job Title: Blind Judge Showdown" bounty. The blind judge compares two job titles at a time and picks the weirder, funnier one.

## The entry

A real-sounding corporate title whose one specific twist is that the counterparty is a raccoon living by the loading dock. It is strange, pictureable and lands on the first read.

## Run it

```sh
node --experimental-strip-types main.ts
```

The program writes a single UTF-8 line of 45 characters to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. There is no clock, randomness, network or secret: two runs write byte-identical output.
